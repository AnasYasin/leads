# ATS boards to poll

One line per company: `board type | slug | name |`. `collect_ats.py` polls every line on every run. A line whose type is `dead` retires that slug. Add a board only with a slug you have tested against the live API; do not edit a slug by guessing. When one starts returning nothing, open the company's careers page, look at what the apply links point to, and correct the slug or the type.

The shipped list is German AI and ML employers, weighted towards Berlin startups, as of October 2026. Remove any you never want to see and add your own.
